## The email

Subject: Maggie, a Ghostty fork, before I announce it

Hi Mitchell,

A heads-up, not an ask.

For the past few months I've been building Maggie, a macOS app for running
many coding agents at once: Claude Code and Codex sessions in a sidebar that
shows what each one is doing, with worktrees, a board, usage and a voice on
top. It is a fork of Ghostty's macOS app. The terminal is yours; the sidebar,
the workspace and the agent side are mine. It is MIT, public on GitHub since
September, and I merge upstream after each Ghostty release so it stays close
to the real thing.

It says "built on Ghostty, not affiliated with the Ghostty project" in the
README, on the site and in the app, and it uses none of your marks beyond that
sentence. If anything about how it credits Ghostty should be different, tell
me and I'll change it.

I'm announcing it publicly in the next few days, on LinkedIn first, and I
didn't want you to find out second-hand.

Repository: https://github.com/marciosete/maggie
Site: https://getmaggie.dev

Thank you for Ghostty. Maggie exists because the terminal underneath it is
that good.

Marcio Sete
